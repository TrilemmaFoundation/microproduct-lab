Archetypes anchor design reviews, prompt packs, and telemetry plans. Pick one before opening a template—the combination encodes most product risk.

Not every archetype has a matching starter. Use the closest starter in [/templates](/templates) when one exists, then quantify maturity via [/standards/maturity-model](/standards/maturity-model).

| Archetype | When to reach for it | Starter |
| --- | --- | --- |
| [Data → decision tool](./data-to-decision-tool.md) | High-stakes spreadsheets need governed automation | [data-app](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/data-app), [dashboard-to-tool](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/dashboard-to-tool) |
| [Ranking recommendation engine](./ranking-recommendation-engine.md) | Users must sift large sets with explainable stacks | No starter yet |
| [Forecasting product](./forecasting-product.md) | Scenario planning dominates the workflow | [analytics-api](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/analytics-api) |
| [Risk scoring product](./risk-scoring-product.md) | Prioritizing assets, liabilities, queues | No starter yet |
| [Alerting monitoring product](./alerting-monitoring-product.md) | Latency-safe guardrails trump dashboards | No starter yet |
| [Search discovery product](./search-discovery-product.md) | Retrieval quality is the primary deliverable | No starter yet |
| [Benchmark evaluation product](./benchmark-evaluation-product.md) | Competing approaches need consistent metrics | [benchmark-suite](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/benchmark-suite), [research-to-product](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/research-to-product) |
| [Simulation backtesting product](./simulation-backtesting-product.md) | Counterfactuals or strategy paths feed decisions | No starter yet |
| [Workflow automation product](./workflow-automation-product.md) | Repeatable human-in-the-loop flows | [agentic-workflow](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/agentic-workflow), [capstone-project](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/capstone-project) |
| [Agentic research product](./agentic-research-product.md) | Multi-step investigation with governance | [llm-app](https://github.com/TrilemmaFoundation/build/tree/main/product-templates/llm-app) |
